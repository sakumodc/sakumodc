## About

I build automated AI workflows, local-first agent systems, and programmatic media pipelines designed to run reliably without constant manual intervention. My core engineering focus is turning repetitive digital production—such as long-form video clipping, multi-app project management, and knowledge retrieval—into self-operating systems powered by LLMs, MCP integrations, and dedicated homelab hardware.
